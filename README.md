# Explore Bantu Languages

Language-teaching website for Swahili, French, Zulu, Xhosa and Portuguese, with Beginner, Intermediate and Advanced levels. Built with React, Vite, Tailwind CSS, GSAP and React Router.

```
npm install
npm run dev     # local preview
npm run build   # production build in dist/
```

Content lives in `src/data/` (languages.js, posts.js, site.js). Add lesson videos by setting `youtube` or `src` on a video slot in `languages.js`.
